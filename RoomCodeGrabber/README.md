# RoomCodeGrabber — 抖音无畏契约房间码自动抓取

自动识别抖音无畏契约直播画面上出现的房间码（格式：3 位大写字母 + 3 位数字，如 `ASD123`），
并立即复制到剪贴板。**从码渲染到屏幕到写入剪贴板，实测延迟一般 ≤70ms（上限 100ms）。**

## 使用

1. 运行 `RoomCodeGrabber.exe`（或 `dotnet run`）
2. 首次启动会弹出全屏遮罩，**拖拽框选浏览器里的直播视频画面**（框住码出现的位置即可，不必是整个视频）
3. 框选完成后自动开始抓取；直播画面出现新码 → 自动复制，窗口/托盘气泡显示码和实测延迟
4. 看下一个直播间时按 `Ctrl+Alt+S` 重新框选

| 热键 | 功能 |
|---|---|
| `Ctrl+Alt+S` | 重新框选抓取区域 |
| `Ctrl+Alt+G` | 开始/停止抓取 |
| `Esc` | 取消框选 |

## 原理与延迟预算

```
抓帧(50fps) -> 预处理 -> 帧变化检测 -> Windows.Media.Ocr 本地OCR -> 正则+混淆纠正 -> 新码判定 -> Win32剪贴板
 ≤20ms 等帧   + ~5ms 抓帧     +          10~40ms OCR            +        <1ms 剪贴板        ≈ 最坏 70ms
```

- 预处理：**先高质量插值放大(默认3x)再 Otsu 二值化/对比度拉伸 + 深色背景自动反色**（顺序很关键：
  先放大再二值化才能保留小字号的抗锯齿圆环，如 0 的内孔）
- OCR 引擎：Windows 自带 `Windows.Media.Ocr`，**必须有 en-US 语言包**（中文引擎对纯字母数字极弱，
  会吞字/乱插空格）。安装：`Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"`。纯本地推理，无网络请求
- 混淆纠正：OCR 常把 O↔0、I↔1、S↔5、B↔8 认错；利用"前 3 位必字母、后 3 位必数字"的格式约束自动纠正；纠正后仍不合格式的文本直接丢弃（宁漏勿错）
- 新码判定：与上一帧可见码集合对比，只有新出现的码才触发；同码 30 秒冷却（可配置），防止画面抖动重复复制
- 剪贴板：Win32 API 同步写入，<1ms

## 构建

```powershell
dotnet publish -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false
# 产物: bin\Release\net8.0-windows10.0.19041.0\win-x64\publish\RoomCodeGrabber.exe
```

配置保存在 exe 同目录 `config.json`（抓取区域、冷却、抓帧间隔、提示音）。

## 已知限制

- 100ms 从"码渲染到你屏幕上"起算（工具无法感知它在主播端/网络中出现的那一刻）
- 抓取区域必须保持可见（被其他窗口遮挡时无法识别）
- 若 Windows 未安装任何 OCR 语言包，首次启动会提示安装
