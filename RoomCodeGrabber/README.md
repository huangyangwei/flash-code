# RoomCodeGrabber — 原生抓码实现说明

统一桌面客户端的安装、启动、配置迁移和发布命令请以仓库根目录的 `README.md` 为准。本文件保留原生 OCR 的实现细节和历史性能记录。

自动识别抖音无畏契约直播画面上出现的房间码（格式：3 位大写字母 + 3 位数字，如 `ASD123`），
并立即复制到剪贴板。下述历史测量来自独立抓码流程；WebView2 合成画面的端到端延迟需另行实测，不能直接套用旧值。

## 使用

1. 运行发布目录中的 `RoomCodeGrabber.exe`（开发环境见根目录说明）
2. 在工作台点击“框选画面区域”，拖拽框选可见直播视频里的码（不必是整个视频）
3. 框选完成后自动开始抓取；直播画面出现新码 → 自动复制，窗口/托盘气泡显示码和实测延迟
4. 看下一个直播间时按 `Ctrl+Alt+S` 重新框选

| 热键 | 功能 |
|---|---|
| `Ctrl+Alt+S` | 重新框选抓取区域 |
| `Ctrl+Alt+G` | 开始/停止抓取 |
| `Esc` | 取消框选 |

## 原理与延迟预算

```
抓帧(50fps) -> 预处理 -> 帧变化检测 -> Windows.Media.Ocr 本地OCR -> 正则+混淆纠正 -> 新码判定 -> Win32剪贴板
 ≤20ms 等帧   + ~5ms 抓帧     +          10~40ms OCR            +        <1ms 剪贴板        ≈ 最坏 70ms
```

- 预处理：**先高质量插值放大(默认3x)再 Otsu 二值化/对比度拉伸 + 深色背景自动反色**（顺序很关键：
  先放大再二值化才能保留小字号的抗锯齿圆环，如 0 的内孔）
- OCR 引擎：Windows 自带 `Windows.Media.Ocr`，**必须有 en-US 语言包**（中文引擎对纯字母数字极弱，
  会吞字/乱插空格）。安装：`Add-WindowsCapability -Online -Name "Language.OCR~~~en-US~0.0.1.0"`。纯本地推理，无网络请求
- 混淆纠正：OCR 常把 O↔0、I↔1、S↔5、B↔8 认错；利用"前 3 位必字母、后 3 位必数字"的格式约束自动纠正；纠正后仍不合格式的文本直接丢弃（宁漏勿错）
- 新码判定：与上一帧可见码集合对比，只有新出现的码才触发；同码 30 秒冷却（可配置），防止画面抖动重复复制
- 剪贴板：Win32 API 同步写入，<1ms

## 构建

```powershell
./scripts/publish-win-x64.ps1
# 产物: artifacts/flash-client-win-x64-.../RoomCodeGrabber.exe 和 app/ 页面资源
```

配置保存在 exe 同目录 `config.json`（抓取区域、冷却、抓帧间隔、提示音、剪贴板清空、自动粘贴和点击坐标）。

## 剪贴板管理

- **自动清空**：复制成功后 `ClipboardClearSeconds` 秒（默认 180）自动清空剪贴板；仅当内容仍是程序写入的房间码才清（期间你复制了别的东西不会误清）。设为 `0` 禁用自动清空
- **手动清空**：主窗体"清空剪贴板"按钮，或托盘图标右键菜单"清空剪贴板"，随时立即清空

## 自动粘贴

统一客户端还可在设置中点“记录光标位置”，3 秒后记录目标窗口内鼠标所在的屏幕坐标；“自动点击”默认关闭。启用后复制成功才按配置延迟先点击目标位置，若同时勾选“自动粘贴”再发送 Ctrl+V。多屏幕布局变化后应重新记录，点击失败会跳过该次粘贴。

勾选主窗体"自动粘贴"后，抓到码写入剪贴板会自动向**当前焦点窗口**粘贴一次（`Ctrl+V`，scancode 级注入，兼容游戏窗口）。使用方式：

1. 把光标点进目标输入框（如游戏房间码输入框、群聊输入框）
2. 等直播画面出现新码 → 自动复制并粘贴

- "粘贴延迟(ms)"（默认 0）可让粘贴等一拍再发，给切窗口留时间；上限 10000
- 同码冷却期内不会重复粘贴；注入前若检测到你正按着 Ctrl，本次跳过
- 已知限制：目标窗口若以更高权限运行（如管理员），注入会被系统（UIPI）拒绝——请以相同权限运行本工具；无畏契约受 Vanguard 反作弊影响，游戏内注入可能无效，需以实际体验为准

## 已知限制

- 100ms 从"码渲染到你屏幕上"起算（工具无法感知它在主播端/网络中出现的那一刻）
- 抓取区域必须保持可见（被其他窗口遮挡时无法识别）
- 若 Windows 未安装任何 OCR 语言包，首次启动会提示安装
