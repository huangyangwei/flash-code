# clipboard-manual-clear Delta

## Purpose

为抓到的房间码提供即时手动清空剪贴板的用户入口，降低误粘贴旧码的风险；与现有延迟自动清空共存，形成"自动兜底 + 手动立刻清"的双通道。

## ADDED Requirements

### Requirement: 主窗体手动清空按钮

系统 SHALL 在主窗体提供"清空剪贴板"按钮；用户点击后，系统 MUST 立即清空剪贴板（不留任何文本格式），无论自动清空延迟是否已到期。

#### Scenario: 点击按钮立即清空

- **WHEN** 剪贴板中存在程序写入的房间码且自动清空延迟尚未到期，用户点击"清空剪贴板"按钮
- **THEN** 剪贴板被立即清空（读取文本返回空/无文本格式），且后续到达的自动清空定时不再执行任何清除动作

#### Scenario: 清空后 UI 反馈

- **WHEN** 用户点击"清空剪贴板"按钮
- **THEN** 界面在短时间内给出可视反馈（如按钮或状态文本短暂提示"已清空"）

### Requirement: 托盘菜单手动清空入口

系统 SHALL 在托盘图标右键菜单提供"清空剪贴板"菜单项，行为与主窗体按钮一致，使主窗体不可见（最小化/后台）时也能清空。

#### Scenario: 主窗体隐藏时经托盘清空

- **WHEN** 主窗体处于隐藏或最小化状态，用户从托盘右键菜单选择"清空剪贴板"
- **THEN** 剪贴板被立即清空

### Requirement: 与自动清空共存

手动清空入口 MUST 与现有 `ClipboardClearSeconds` 延迟自动清空共存：自动清空行为保持不变；`ClipboardClearSeconds = 0` 时系统 SHALL 不自动清空，仅保留手动清空作为唯一清除途径。

#### Scenario: 秒数为 0 时纯手动

- **WHEN** `ClipboardClearSeconds` 配置为 0 且程序抓到新码写入剪贴板
- **THEN** 剪贴板内容持续保留，直到用户手动触发清空或下一次写入覆盖

#### Scenario: 自动清空不受手动入口影响

- **WHEN** `ClipboardClearSeconds` 大于 0 且用户在延迟到期前已手动清空
- **THEN** 延迟到期后系统不重复清空、不报错、不产生可见副作用
